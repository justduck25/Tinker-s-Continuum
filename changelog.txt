Continuum Construct 26.1.2-3.12.1

This release repairs the luck modifier, which did nothing in 3.12.0.0, and stops the debug modifier command from pushing modifiers past their crafting cap. It also fixes large smelteries closing their own screen and the blaze head rendering as a black cube.

Fixes
- Luck once again grants fortune, looting, and luck of the sea. NeoForge 26 removed LootingLevelEvent, so modifier looting is now applied through EnchantedEntityLootEvent for melee, projectile, and bleeding kills.
- Enchantments granted by modifiers are matched by registry key instead of object identity, so datapack copies of fortune, looting, luck of the sea, and soul speed are recognised again.
- Fixed fortune dropping roughly double the intended items. Modifier enchantments written onto the tool for block loot were counted a second time by the tool's own enchantment level lookup.
- Luck is back to the 3.12 module set of constant fortune, weapon looting, armor fortune, armor looting, armor luck, and sea luck, replacing a custom module that applied only one of the three enchantments.
- /tconstruct modifiers add no longer raises a modifier above the highest level its recipes can reach. Modifiers with no recipe, such as material traits, remain uncapped since no cap is defined for them.
- /tconstruct modifiers remove now clears raw modifier NBT when the level reaches zero, instead of leaving stale data on the tool.
- Fixed the smeltery and foundry screen closing by itself whenever the contents changed in a structure with more than 255 melting slots, such as a 9x5x9 interior. Slot counts and indices were saved as bytes, so the client saw a truncated slot count and dropped the screen on the next update. Items sitting in slots past 255 were also lost on save.
- Fixed multiblock structures never loading back from saved data. Positions are written as x/y/z compounds but were read with the int array codec, so smelteries and foundries came back without a structure after a reload.
- Fixed the blaze head item rendering as a black cube. Its item model pointed at textures/entity/blaze.png, which Minecraft 26.1 moved to textures/entity/blaze/blaze.png.

Compatibility
- Requires Continuum Core 1.12.0.
- Built against Minecraft 26.1.2 / NeoForge 26.1.2.109.

Continuum Construct 26.1.2-3.12.0.0

This release ports remaining Tinkers' Construct 3.12 gameplay onto NeoForge 26.1 and includes smeltery, anvil, and rendering fixes that landed after 3.11.9.1.

New
- Added fancy armor stands in bamboo, bone, clear glass, and necrotic bone variants, with dispenser support and custom rendering.
- Added cheese, horn, and nautilus materials, plus the matching 3.12 honey, phantom, prismarine, and slimesuit material updates.
- Added 3.12 slimesuit traits and related modifiers, including ram attack, shell gut, savory, scrumptious, and thorns shell.
- Creeper slimeskulls now use gunpowder instead of glass, with the 3.12 skull trait wrappers for consecrated, respiration, vital protection, and withered bones.
- Feather Falling is now Feather Fall with 3.12 multi-level recipes. Long Fall requires four Feather Fall levels.
- Tinkers tools and armor can now grant the matching vanilla story, nether, and husbandry advancements.
- Fluid cannons can be equipped on the head.
- Enderbark roots are tagged so Create root harvesters treat them like mangrove-style roots.

Improvements
- Slimesuit armor models now cover chestplate, leggings, and wing overlays, including broken states.
- Tasty, savory, and scrumptious now show hunger and saturation on tooltips.
- Material and modifier rarity now writes to Minecraft 26.1 item rarity components so names color correctly in inventories.
- Hide-cleaning composite recipes are hidden from the in-game book.
- Left-click cycles the selected sliver slimeball slot, and sliver ammo is used before the player inventory.
- Slimeball projectiles keep the original Tinkers fireball speed. After hitting a wall they bounce once, then veer left, right, up, or down and continue at that speed.
- Empty-handed mobs wearing slimecage can use unarmed chest attacks.
- Clear fancy item frames now craft from Tinkers clear glass instead of vanilla glass panes.

Fixes
- Fixed Tinkers and scorched anvil hitboxes facing the wrong way (#16).
- Fixed smeltery and melter fluid state after reloads and faucet use, including drains, ducts, tanks, and in-progress casting (#18).
- Fixed retained tank, gauge, lantern, and casting tank fluids not rendering on item stacks after the block is broken (#13).
- Fixed retained tank item tooltips reading the wrong saved fluid format on some dropped tanks.
- Fixed smeltery drains and ducts losing their structure connection after reloading a world while a redstone faucet was active (#14).
- Fixed casting recipes remaining molten if the world was exited before cooling completed.
- Fixed duct filters losing stored copper cans or fluid containers after reloading, and modded fluid buckets not being accepted as duct filters.
- Fixed faucet redstone handling and melter hopper input.
- Fixed JEI entity melting and severing recipe layouts crashing from mismatched focus links.
- Fixed 26.1 casting, JEI, and bamboo armor stand rendering issues from the 3.12 gadget port.
- Projectile fiery, freeze, bounce, and related slimeball effects now persist instead of being lost on each capability lookup.
- Slimeball ammo matches correctly when 26.1 datapack tags are unbound during recipe load.
- Sky slime, ender slime, and terracube loot tables now generate valid 26.1 loot.
- Frog and shulker entity melting now uses dedicated entity type tags.
- Combat fishing hooks stay in sync on 26.1.
- Held-tool loot modifiers only run for melee damage sources they should apply to.

Compatibility
- Requires Continuum Core 1.12.0.
- Built against Minecraft 26.1.2 / NeoForge 26.1.2.109.

Continuum Construct 26.1.2-3.11.9.1

Fixes
- Fixed a crash when Continuum Construct was loaded without JEI installed.
- JEI integration now stays optional and only hooks recipe sync when JEI is present.

Compatibility
- Updated the required Continuum Core dependency to 1.11.6.
- Built against NeoForge 26.1.2.109.

Continuum Construct 26.1.2-3.11.9

New
- Added AllTheModium family material compatibility for Allthemodium, Vibranium, and Unobtainium.
- Added molten fluids, melting recipes, casting recipes, material stats, traits, and generated tool textures for the three main AllTheModium metals.
- AllTheModium materials are made through smeltery casting only; Part Builder recipes are intentionally disabled for these materials.

Improvements
- Updated AllTheModium material colors so Continuum tools better match the original AllTheModium tool palette.
- Added matching harvest tiers for Allthemodium, Vibranium, and Unobtainium harvest tools.

Fixes
- Fixed cleaver/severing drops copying early-loaded recipe outputs with temporary direct item holders, which could spam NBT predicate warnings after pickup.
- Fixed AllTheModium ores refusing to break even when Continuum tools displayed the correct harvest tier.
- Added vanilla tool component syncing so mods that check DataComponents.TOOL can recognize Continuum harvest tools correctly.
- Fixed older Continuum tools missing the new vanilla tool component after loading an existing world.
- Fixed a crash caused by trying to create registry lookups after Minecraft registries were already frozen.

Tested
- compileJava, runClientData, runClient, and assemble passed.
