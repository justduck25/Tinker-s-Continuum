Tinkers' Continuum 26.1.2-3.11.3

Compatibility
- Added material and tool part compatibility for AE2, Advanced AE, ExtendedAE, Ender IO, Powah, and Jade.
- Added item-only armor part recipes for supported compat materials so armor pieces can be crafted consistently.
- Added world loot integration for generated Tinkers' tools with more controlled modifier pools.
- Added Apotheosis and Apothic Enchanting support for higher modifier caps and vanilla-style enchantment conversion where supported.
- Added safer recipe visibility and conditional loading for optional compat content.

Fixes
- Fixed Smeltery recipe sync crashes caused by missing or empty optional tags, including raw steel materials.
- Fixed slime embellishment recipes by restoring the missing TCon slime embellishment tool tag.
- Fixed several JEI recipe display issues for compat materials, casting, and tool part recipes.
- Fixed luck tooltip and enchantment naming so tools show the correct vanilla-style effect such as Fortune, Looting, or Luck of the Sea.
- Fixed tool loot balance so world-generated tools no longer roll too many random modifiers.
- Fixed white or missing models for AE2-family compat materials including Certus Quartz, Fluix, Quantum, and Entro.
- Improved Mantle recipe network errors so broken synced recipes report the failing recipe ID.

Version Safety
- Restricted NeoForge compatibility to 26.1.2.78 or newer, below 26.2, so unsupported loader versions fail with a clear dependency message.
- Verified NeoForge 26.1.2.77 is rejected with the expected loader warning.
