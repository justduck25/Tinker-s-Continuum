Continuum Construct 26.1.2-3.11.9

New
- Added AllTheModium family material compatibility for Allthemodium, Vibranium, and Unobtainium.
- Added molten fluids, melting recipes, casting recipes, material stats, traits, and generated tool textures for the three main AllTheModium metals.
- AllTheModium materials are made through smeltery casting only; Part Builder recipes are intentionally disabled for these materials.

Improvements
- Updated AllTheModium material colors so Continuum tools better match the original AllTheModium tool palette.
- Added matching harvest tiers for Allthemodium, Vibranium, and Unobtainium harvest tools.

Fixes
- Fixed cleaver/severing drops copying early-loaded recipe outputs with temporary direct item holders, which could spam NBT predicate warnings after pickup.
- Fixed AllTheModium ores refusing to break even when Continuum tools displayed the correct harvest tier.
- Added vanilla tool component syncing so mods that check DataComponents.TOOL can recognize Continuum harvest tools correctly.
- Fixed older Continuum tools missing the new vanilla tool component after loading an existing world.
- Fixed a crash caused by trying to create registry lookups after Minecraft registries were already frozen.

Tested
- compileJava, runClientData, runClient, and assemble passed.
